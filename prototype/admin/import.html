Import voters

Upload a CSV or Excel (.xlsx) file. You will see a preview with duplicates and problems highlighted before anything is saved.

Download CSV template
First row must contain column headings. Recognised columns: Voter ID (or Member ID), Full Name (or Name, or First/Last name), Email, Mobile (or Phone), WhatsApp, Batch (or Year).

How repeat imports work

  • Each person keeps one stable voter record. Rows are matched to existing voters by Voter ID, or by the same name with the same email (or mobile).
  • Matched rows update contact details, they never create a second voter or a second voting entitlement.
  • Shared emails or phone numbers are flagged as possible duplicates for review, but nobody is disqualified automatically.
  • Missing email or phone is allowed and reported.
