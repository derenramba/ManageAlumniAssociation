Election workflow

  1. Configure election settings (dates, support contact)
  2. Create positions, add & approve candidates, mark unopposed posts
  3. Import or add voters, review duplicates, then approve the final voter list
  4. Generate voting codes one per eligible voter
  5. Preview and send invitations
  6. Open voting, monitor turnout, then close the election
  7. Review results, export, and publish
